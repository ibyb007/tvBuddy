# backdrop (vendored)

Real-time backdrop blur / lens refraction / edge highlight for Compose, used by the floating navbar.

Source: Kyant0/backdrop v2.0.0 (https://github.com/Kyant0/backdrop),
Copyright 2025 Kyant0, licensed under the Apache License 2.0
(https://www.apache.org/licenses/LICENSE-2.0).

Taken from the vendored copy in danielkanan/Yuno, which merges the KMP expect/actual declarations into
one Android source set and adds a backdrop resolution scale (`backdropScale`) plus a record-once
`layerBackdrop`. Package renamed to `com.example.ui.backdrop`. Per-file headers are kept as-is.
